# To-Do-Assistant
一款轻量化、高颜值Windows桌面待办助手，集成透明桌面悬浮插件，对标小黄条体验。软件支持待办清单、分类管理、优先级标注、定时提醒、文件附件等高效办公功能，底部快捷输入可一步完成待办创建，无需二次编辑。 内置可自定义透明桌面插件，支持自由缩放、拖拽移动，提供多套主题配色与透明度调节。插件可展示实时时间、农历日期、天气、日历及待办任务，支持今日/一周/本月/全部任务筛选，支持桌面直接完成待办，数据实时双向同步。插件仅显示在桌面层，不遮挡其他应用，支持开机随软件自启。 搭载多方式同步备份功能，支持局域网同步、本地文件备份、WebDAV云同步，保障数据安全。软件体积小巧、低占用、无广告，兼顾日常办公、学习日程与桌面极简美化需求。
